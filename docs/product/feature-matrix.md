# Spoon feature matrix

Last updated: 2026-10-11.

How to read this table:

- **Status**: `Done` (implemented end to end), `Partial` (usable with stated gaps), `Experimental` (works against documented APIs but not verified against a live service), `Planned` (not implemented).
- **Verification**: `Integration` = automated test against real Git with disposable repositories (`tests/integration`), `Unit` = automated test of pure logic (`tests/unit`), `E2E` = Playwright test driving the packaged-equivalent Electron app (`tests/e2e`), `Manual` = exercised by hand during development, `Untested` = no verification yet.
- **Platforms**: all automated verification ran on Windows 11 (x64) with Git 2.33. macOS and Linux are expected to work (no Windows-only code paths in features) but are **untested**.

Priority: P0 = core daily workflow, P1 = expected in a full-featured Git client, P2 = differentiators / nice to have.
